# ربات دانلودر تلگرام (اینستاگرام / پینترست / تیک‌تاک)

فقط ۳ فایل: `main.py` (کل منطق ربات)، `requirements.txt`، `Dockerfile`.

## ۱. ساخت ربات در تلگرام
به [@BotFather](https://t.me/BotFather) پیام بده، `/newbot` رو بزن، یه توکن می‌گیری شبیه:
`123456789:AAExampleTokenXXXXXXXXXXXXXXXXXXXXX`

## ۲. دیپلوی روی Railway
۱. این ۳ فایل رو توی یه ریپوی گیت‌هاب بریز.
۲. توی Railway → New Project → Deploy from GitHub repo → همون ریپو رو انتخاب کن.
   (Railway خودش `Dockerfile` رو تشخیص می‌ده، نیازی به تنظیم اضافه نیست.)
۳. تب **Variables** → یه متغیر اضافه کن:
   - `BOT_TOKEN` = توکنی که از BotFather گرفتی
۴. صبر کن دیپلوی تموم بشه. توی تب **Deployments → Logs** باید پیام `ربات در حال اجراست...` رو ببینی.

همین. بقیه‌ی تنظیمات (حجم مجاز فایل، تعداد دانلود همزمان و...) پیش‌فرض دارن و نیازی به تغییر نیست — اگه خواستی عوضشون کنی، این متغیرهای اختیاری رو هم می‌تونی توی Variables اضافه کنی:

```
MAX_FILE_SIZE_MB=50
MAX_CONCURRENT_DOWNLOADS=3
RATE_LIMIT_SECONDS=3
```

## وضعیت پلتفرم‌ها
- ✅ اینستاگرام، پینترست، تیک‌تاک (ویدیو + عکس)
- ⏳ یوتیوب — بعدا اضافه می‌شه

نکته: yt-dlp اصلی برای ویدیو ساخته شده. برای **پست‌های عکسی** اینستاگرام/پینترست
که yt-dlp نتونه پردازششون کنه، ربات خودکار سراغ یه روش جایگزین می‌ره
(استخراج تگ `og:image` از خود صفحه) تا عکس رو بگیره.

## اگه کار نکرد
لاگ Railway (Deployments → Logs) رو چک کن و برام بفرست تا دیباگ کنیم.
