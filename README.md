# ربات دانلودر تلگرام (اینستاگرام / توییتر / یوتیوب / پینترست / تیک‌تاک)

فقط ۳ فایل: `main.py`، `requirements.txt`، `Dockerfile`.

## ۱. ساخت ربات در تلگرام
از [@BotFather](https://t.me/BotFather) با `/newbot` یه توکن بگیر.

## ۲. دیپلوی روی Railway
۱. این ۳ فایل رو توی ریپوی گیت‌هاب بریز.
۲. Railway → New Project → Deploy from GitHub repo.
۳. تب **Variables**:
   - `BOT_TOKEN` = توکن ربات (اجباری)

همین کافیه برای شروع. لاگ `ربات در حال اجراست...` یعنی آماده‌ست.

## کوکی (برای بهبود نرخ موفقیت)

بدون کوکی، پست‌های عکسی اینستاگرام و برخی لینک‌های یوتیوب/توییتر شکست می‌خورن.
اگه خواستی کوکی اضافه کنی:

۱. با اکستنشن مرورگر «Get cookies.txt LOCALLY» وارد اکانت (ترجیحاً فرعی) بشو و کوکی رو export کن.
۲. محتوای فایل `cookies.txt` رو با این دستور به base64 تبدیل کن:
   ```bash
   base64 -w 0 cookies.txt
   ```
۳. خروجی رو به‌عنوان یکی از این متغیرها توی Railway اضافه کن:
   - `INSTAGRAM_COOKIES_B64`
   - `YOUTUBE_COOKIES_B64`
   - `TWITTER_COOKIES_B64`

هر پلتفرمی که کوکی نداشته باشه، بدون کوکی (best effort) امتحان می‌شه.

## وضعیت پلتفرم‌ها

| پلتفرم | ویدیو | عکس/کاروسل | کپشن | نیاز به کوکی |
|---|---|---|---|---|
| اینستاگرام | ✅ | ⚠️ نیاز به کوکی | ✅ | توصیه‌شده |
| توییتر (X) | ✅ | ✅ | ✅ | توصیه‌شده |
| یوتیوب | ⚠️ نیاز به کوکی/پروکسی | - | ✅ | توصیه‌شده |
| پینترست | ⚠️ محدود | ✅ | ✅ | لازم نیست |
| تیک‌تاک | ✅ | ✅ | ✅ | لازم نیست |

## محدودیت‌های مهم (واقع‌بینانه)

- **یوتیوب**: از سرورهای دیتاسنتری (مثل Railway) اغلب بلاک می‌شه، چون سیستم تشخیص بات یوتیوب سخت‌گیرانه‌ست. کوکی به‌تنهایی معمولاً کافی نیست؛ ممکنه به پروکسی رزیدنشیال هم نیاز باشه.
- **پینترست**: yt-dlp رسماً از پین‌های عکسی پشتیبانی نمی‌کنه (تصمیم خودشونه). ربات از gallery-dl و og:image استفاده می‌کنه، ولی پینترست هم فعالانه جلوی دسترسی خودکار رو می‌گیره؛ موفقیت تضمینی نیست.
- **اینستاگرام**: از اوایل ۲۰۲۶ عکس/کاروسل بدون کوکی عملاً قابل دانلود نیست (ویدیو/ریلز معمولاً بدون کوکی هم کار می‌کنه).
- کوکی‌ها منقضی می‌شن (چند هفته‌ای) و باید گاهی دوباره export و آپدیت بشن.
- حداکثر حجم فایل قابل ارسال: ۵۰ مگابایت.

## اگه کار نکرد
لاگ Railway (Deployments → Logs) رو چک کن؛ اگه پیام خطای خاصی هست برام بفرست.
